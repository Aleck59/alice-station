# Запуск

## 1. Сначала на компьютере (эмулятор)

Так проверяется связка с xiaozhi.me без колонки: микрофон и динамик компьютера.
Нужны Linux, Python 3.11+, `alsa-utils` (arecord/aplay), `libopus`.

```sh
git clone https://github.com/Aleck59/alice-station
cd alice-station
pip install -r agent/requirements.txt
ALICE_STATION_DIR=./.local PYTHONPATH=agent python3 -m alice_station --pc
```

1. В логе появится `КОД АКТИВАЦИИ: 123456`. Он же — на панели <http://127.0.0.1:8060/>.
2. Зайдите на [xiaozhi.me](https://xiaozhi.me) → консоль → добавить устройство → введите код.
   Там же выберите модель, роль (системный промпт) и **голос** агента.
3. Через несколько секунд агент напишет «устройство активировано».
4. На панели нажмите «Говорить» и задайте вопрос. Повторное нажатие во время ответа
   перебивает, во время слушания — заканчивает диалог.

Токен и UUID сохраняются в `./.local/state.json` — это «личность» устройства в
xiaozhi.me, не публикуйте этот файл.

## 2. На Станции Миди

Нужно: [root и SSH](https://hackalice.me/start/root/),
[отключённые обновления](https://hackalice.me/start/ssh/),
[Entware в /opt](https://hackalice.me/recipes/packagemanagers/).

```sh
# с компьютера
scp -P 2222 -r alice-station root@<IP-колонки>:/tmp/
ssh -p 2222 root@<IP-колонки>
# на колонке
cd /tmp/alice-station && sh deploy/install.sh
```

Установщик:

- ставит из Entware `python3`, `python3-pip`, `python3-cffi`, `libopus`, `alsa-utils`;
- ставит Vosk и скачивает малую русскую модель (~45 МБ) для слова вызова
  (`AS_NO_WAKEWORD=1` — пропустить);
- кладёт агент в `/data/opt/alice-station`, конфиг и состояние — в `/data/alice-station`;
- проверяет захват микрофона через `alice_mic` (96 кГц на железе → 16 кГц для нас) и
  что Алиса продолжает слышать;
- ставит автозапуск `/etc/init.d/S99zzalice-station` (перемонтирует `/` на запись).

Дальше — как на компьютере: панель `http://<IP-колонки>:8060/`, код активации, xiaozhi.me.
Режимы и голосовое переключение — в следующем разделе.

### Управление

```sh
/etc/init.d/S99zzalice-station restart     # перезапуск
tail -f /data/alice-station/agent.log      # лог
touch /data/alice-station/disabled         # не запускать при загрузке
```

### Откат

```sh
sh /data/opt/alice-station/deploy/uninstall.sh --dry-run   # показать план
sh /data/opt/alice-station/deploy/uninstall.sh             # удалить, настройки оставить
sh /data/opt/alice-station/deploy/uninstall.sh --purge     # удалить вместе с токенами
```

Штатные файлы Алисы (`quasar.cfg`, `launch.json`) агент не меняет.

## 3. Режимы: Алиса (сток) ⇄ ассистент

После загрузки колонка — **обычная Алиса**: агент не трогает микрофон и ничего не перехватывает.

| Что сказать | Что произойдёт |
|---|---|
| «Алиса, включи ассистента» | агент ловит фразу в локальном IPC Алисы (`127.0.0.1:9875`), гасит её ответ (на секунду убирает громкость и отменяет диалог) и говорит голосом Алисы «Катя на связи…» |
| «Катя, …» или «Лариса, …» | разговор с XiaoZhi (слово вызова распознаёт Vosk на колонке) |
| «Катя» во время ответа | перебить ответ |
| «Катя, верни к Алисе» (или «выключи ассистента») | агент закрывает диалог и говорит «Возвращаю Алису» — дальше снова сток |
| «Алиса, …» в режиме ассистента | отвечает штатная Алиса, как обычно |

Переключать можно и в панели (раздел «Режим»). Имя, фразы и слова вызова — в разделах
`[assistant]` и `[wakeword]` конфига.

!!! warning "Что может мешать"
    - Ответ Алисы на «включи ассистента» гасится после распознавания фразы, поэтому первые
      доли секунды её ответа могут проскочить (то же ограничение описано у MidiPult).
    - «Лариса» и «к Алисе» звучат похоже на «Алиса», и штатный споттер Алисы может
      проснуться. Если мешает, оставьте в `words` только «катя», а для выхода говорите
      «выключи ассистента».
    - В режиме ассистента кнопка Алисы запускает и XiaoZhi, и Алису. Лучше голосом.
    - Формат IPC проверен сообществом на Станции 2, а озвучка через него — на Миди (MidiPult).
      Кадр отмены ответа Алисы взят из описания derangedabbot, на Миди не проверялся.

## 4. Голоса

В `config.toml` (`/data/alice-station/config.toml`) — раздел `[voice.profiles.*]`, примеры
в [deploy/config.example.toml](../deploy/config.example.toml):

| engine | Что это |
|---|---|
| `cloud` | голос, выбранный в xiaozhi.me |
| `command` | любая программа: текст в stdin → PCM S16 моно в stdout (Piper `--output-raw`) |
| `http` | OpenAI-совместимый `/audio/speech` |

Сменить голос: в панели, или голосом — «смени голос на …» (MCP-инструмент
`self.voice.set_profile`).

## 5. Что умеет голосом (MCP-инструменты)

| Инструмент | Пример фразы |
|---|---|
| `self.audio_speaker.set_volume` | «сделай погромче», «громкость 30» |
| `self.light.set_rgb`, `self.light.off` | «включи зелёную подсветку» |
| `self.timer.set/list/cancel` | «таймер на пять минут» |
| `self.voice.list_profiles/set_profile` | «какие есть голоса?» |
| `music.radio.list/play`, `music.pause/resume/stop/next` | «включи Европу Плюс» |
| `music.vk.*` | пока отвечает, что ВК не подключён |
| `self.assistant.return_to_alice` | «вернись к Алисе» в любой формулировке |

Модель в xiaozhi.me сама решает, когда вызвать инструмент, — по описанию инструмента.

### С MidiPult: дисплей, кольцо и всё, что умеет Алиса

Если на колонке стоит [MidiPult](https://github.com/RoBiN19666/midipult) (он поднимает
Luna на `:8099` и CGI на `:8055`), агент сам находит его и добавляет инструменты:

| Инструмент | Пример фразы |
|---|---|
| `self.display.show_text` | «Катя, напиши на часах HELLO» |
| `self.display.show_time`, `set_brightness`, `off`, `on` | «верни часы», «сделай часы ярче», «погаси экран» |
| `self.light.set_colors`, `set_rgb`, `off`, `set_brightness` | «сделай кольцо радугой», «подсветку потише» |
| `alice.send_command` | «Катя, попроси Алису включить свет в спальне» / «…включить мою волну» |
| `alice.player.control`, `alice.player.status` | «следующий трек», «что играет?» (плеер Алисы) |
| `midipult.radio.list/play/stop` | «включи радио Рекорд» |
| `midipult.scenario.list/run` | «запусти сценарий Утро» |
| `midipult.vpn.set/status` | «включи VPN» |
| `midipult.bluetooth.set` | «включи режим сопряжения Bluetooth» |
| `self.system.status`, `midipult.zigbee.devices` | «какая температура процессора?», «какие есть датчики?» |

`alice.send_command` передаёт текст штатной Алисе через Glagol — так ассистенту доступны
умный дом Яндекса, Яндекс Музыка, будильники и остальные навыки Алисы.

Циферблат семисегментный: латиница без K M V W X Z и цифры, поэтому русский текст на нём
не показать. Мост выключается в конфиге: `[midipult] enabled = false`.
