# Роадмап

Отметки [x] — код написан и покрыт тестами без железа; проверка на колонке — отдельно.

Каждый этап заканчивается чем-то, что можно проверить руками на колонке.

## Этап 0. Подготовка колонки { #stage-0 }

- [ ] Root и SSH на Миди по [DNS-методу](https://hackalice.me/start/root/).
- [ ] [Отключить обновления](https://hackalice.me/start/ssh/), закрепить ADB.
- [ ] Записать версию прошивки (`0.369…` или `factory-6`) в `docs/device-midi.md`.
- [ ] Entware в `/opt`, `python3`, `libopus`.

**Готово, когда:** есть SSH и колонка не обновляется.

## Этап 1. Клиент XiaoZhi на ПК { #stage-1 }

- [x] Модуль активации: `POST /xiaozhi/ota/`, разбор `activation`/`websocket`.
- [x] WebSocket-клиент: `hello`, `listen`, Opus вверх/вниз, `abort`.
- [x] Минимальный MCP: `initialize`, `tools/list`, `tools/call`.
- [x] Эмулятор колонки на ПК (микрофон/динамик ноутбука).

**Готово, когда:** ноутбук добавлен как устройство в xiaozhi.me и отвечает голосом.

## Этап 2. Агент на колонке, запуск по кнопке { #stage-2 }

- [x] Захват `hw:0,1` @ 96 кГц параллельно с Алисой, ресемплинг в 16 кГц.
- [x] Воспроизведение ответа в ALSA `default`.
- [x] Запуск диалога кнопкой и из веб-панели.
- [ ] Запуск фразой «Алиса, включи нейросеть» (через Luna, как MidiPult).
- [x] Код активации — в веб-панели и логе, голосом при локальном TTS (на часах — после разметки сегментов).
- [x] `deploy/install.sh`, `uninstall.sh`, автозапуск, откат.

**Готово, когда:** «Алиса, включи нейросеть» → вопрос → ответ модели XiaoZhi из колонки.

## Этап 3. Голос и устройство { #stage-3 }

- [x] MCP: громкость, кольцо/логотип (`/dev/fb0`, `/dev/fb1`), часы, таймеры.
- [ ] Эмоции из `llm` → анимации кольца (сейчас — анимации по состоянию).
- [x] Голосовые профили: облачный голос xiaozhi.me, Piper, голос Алисы, свой URL.
- [x] Перебивание (`abort`) кнопкой и голосом.

**Готово, когда:** «сделай потише», «смени голос на …», «поставь таймер» работают через LLM.

## Этап 4. Музыка ВК { #stage-4 }

- [ ] Выяснить, каким способом можно легально получать поток и рекомендации ВК
      на устройстве от аккаунта пользователя.
- [ ] MCP: поиск, play/pause/next, лайк, «моя волна» (рекомендательный поток / VK Микс).
- [ ] Плеер: очередь, приглушение музыки на время диалога.

Открытые вопросы:

- Какой доступ к аудио ВК стабильно работает в 2026 году без официального SDK для
  колонок; что требует подписки VK Музыки.
- Работа без подписки и без рекламы зависит от правил ВК; обход платного доступа
  в проект не входит.

**Готово, когда:** «включи мою волну» играет рекомендации из аккаунта ВК.

## Этап 5. Своё слово активации и отключение Алисы { #stage-5 }

- [ ] Локальный KWS (openWakeWord / sherpa-onnx), своё слово.

**Готово, когда:** колонка работает без облака Яндекса.
