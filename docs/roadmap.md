# Роадмап

Каждый этап заканчивается чем-то, что можно проверить руками на колонке.

## Этап 0. Подготовка колонки { #stage-0 }

- [ ] Root и SSH на Миди по [DNS-методу](https://hackalice.me/start/root/).
- [ ] [Отключить обновления](https://hackalice.me/start/ssh/), закрепить ADB.
- [ ] Записать версию прошивки (`0.369…` или `factory-6`) в `docs/device-midi.md`.
- [ ] Entware в `/opt`, `python3`, `libopus`.

**Готово, когда:** есть SSH и колонка не обновляется.

## Этап 1. Клиент XiaoZhi на ПК { #stage-1 }

- [ ] Модуль активации: `POST /xiaozhi/ota/`, разбор `activation`/`websocket`.
- [ ] WebSocket-клиент: `hello`, `listen`, Opus вверх/вниз, `abort`.
- [ ] Минимальный MCP: `initialize`, `tools/list`, `tools/call`.
- [ ] Эмулятор колонки на ПК (микрофон/динамик ноутбука).

**Готово, когда:** ноутбук добавлен как устройство в xiaozhi.me и отвечает голосом.

## Этап 2. Агент на колонке, запуск по кнопке { #stage-2 }

- [ ] Захват `hw:0,1` @ 96 кГц параллельно с Алисой, ресемплинг в 16 кГц.
- [ ] Воспроизведение ответа в ALSA `default`.
- [ ] Запуск диалога: фраза «Алиса, включи нейросеть» (через Luna, как MidiPult) или
      сенсорная кнопка.
- [ ] Код активации — голосом и на LED-часах.
- [ ] `deploy/install.sh`, `uninstall.sh`, автозапуск, откат.

**Готово, когда:** «Алиса, включи нейросеть» → вопрос → ответ модели XiaoZhi из колонки.

## Этап 3. Голос и устройство { #stage-3 }

- [ ] MCP: громкость, кольцо/логотип (`/dev/fb0`, `/dev/fb1`), часы, таймеры.
- [ ] Эмоции из `llm` → анимации кольца.
- [ ] Голосовые профили: облачный голос xiaozhi.me, Piper, голос Алисы, свой URL.
- [ ] Перебивание (`abort`) кнопкой и голосом.

**Готово, когда:** «сделай потише», «смени голос на …», «поставь таймер» работают через LLM.

## Этап 4. Музыка ВК { #stage-4 }

Реализация — отдельная служба [`vk-music`](../vk-music/README.md) рядом с MidiPult.

- [x] Способ доступа: VK API от имени аккаунта пользователя, токен через страницу
      входа ВК (клиент Kate Mobile). Условия ВК для аккаунта соблюдаются, обходов нет.
- [x] Поиск, play/pause/next/prev, лайк, «моя волна» (VK Микс → рекомендации).
- [x] Плеер: очередь, подгрузка волны, пауза на время ответа Алисы.
- [x] Голосовые команды через сценарии MidiPult («Алиса, включи мою волну ВК»).
- [ ] Проверить на колонке: вход, воспроизведение (mp3/HLS через GStreamer прошивки),
      громкость, паузу во время диалога.
- [ ] Поиск голосом («включи ВК Кино»): сценарии MidiPult не передают текст —
      нужен свой обработчик фраз.
- [ ] MCP-инструменты агента вызывают HTTP API службы.

Открытые вопросы:

- Отдаёт ли ВК поток VK Микс клиенту Kate Mobile; если нет — «волна» строится из
  рекомендаций.
- Обход платного доступа и рекламы в проект не входит.

**Готово, когда:** «включи мою волну ВК» играет рекомендации из аккаунта ВК.

## Этап 5. Своё слово активации и отключение Алисы { #stage-5 }

- [ ] Локальный KWS (openWakeWord / sherpa-onnx), своё слово.
- [ ] Эхоподавление (LOOPBACK-A + AEC или VQE-поток).
- [ ] Режим «без Алисы»: убрать `maind` из `launch.json` с документированным откатом.
- [ ] Веб-панель (своя или модуль MidiPult).

**Готово, когда:** колонка работает без облака Яндекса.
