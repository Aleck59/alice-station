# Alice Station

**Полноценная замена штатной Алисы на Яндекс Станции Миди.**

Цель проекта — превратить рутованную Станцию Миди в независимого голосового ассистента:

- 🤖 **LLM от [xiaozhi.me](https://xiaozhi.me)** — колонка говорит с облаком XiaoZhi по его
  открытому протоколу (WebSocket + Opus + MCP), как ESP32-устройства из
  [78/xiaozhi-esp32](https://github.com/78/xiaozhi-esp32). Модель, роль и память
  настраиваются в консоли xiaozhi.me.
- 🔊 **Настраиваемый голос** — голос выбирается в xiaozhi.me, а локально можно подменить
  синтез на свой TTS (профили голосов, переключение командой или из веб-панели).
- 🎵 **Музыка из ВКонтакте** — поиск, плейлисты и рекомендательный поток в духе «Моей волны»
  через аккаунт пользователя; управление голосом через MCP-инструменты.
- 💡 **Железо Миди** — кольцо, логотип и LED-часы, сенсорные кнопки, громкость.

> [!IMPORTANT]
> Проект неофициальный и не связан с ООО «Яндекс» или Xiaozhi. Всё — только для своих
> устройств и на свой риск. Не публикуйте ключи, токены, MAC-адреса и серийные номера.

## Структура репозитория (план)

```text
docs/            архитектура, роадмап, заметки по устройству
agent/           демон на колонке: аудио, клиент XiaoZhi, MCP-инструменты
  xiaozhi/       клиент протокола XiaoZhi (OTA/активация, WebSocket, Opus)
  audio/         захват микрофонов, воспроизведение, слово активации
  tools/         MCP-инструменты колонки: громкость, LED, музыка, таймеры
  voice/         голосовые профили и локальный TTS
  music/         провайдер музыки ВК
panel/           веб-панель настроек (локальная сеть)
deploy/          установка/удаление на колонке, init-скрипты, откат
tools/           утилиты для ПК: эмулятор колонки, тесты протокола
```
