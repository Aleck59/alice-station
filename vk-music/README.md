# VK Музыка на Станции Миди

Служба `vk-music` играет музыку из вашего аккаунта ВКонтакте на рутованной Станции Миди
с [MidiPult](https://github.com/RoBiN19666/midipult). Работает рядом со штатной Алисой:
Алиса остаётся как есть, а музыка ВК включается голосом через сценарии MidiPult или
с веб-страницы службы.

> [!IMPORTANT]
> Служба слушает от имени вашего аккаунта и получает то, что ВК отдаёт этому аккаунту.
> Ограничения бесплатного тарифа она не обходит и рекламу не вырезает: если ВК ограничит
> прослушивание, служба покажет ошибку ВК, а обходных приёмов в проект не добавляем.
> Проект неофициальный и не связан с VK.

## Как это устроено

```
голос → Алиса распознаёт → MidiPult voice_daemon → сценарий «ВК: …» → GET http://127.0.0.1:8061/…
                                                                              │
веб-страница http://<ip>:8061 ───────────────────────────────────────────────►│ vk-music (Python, Entware)
                                                                              │   ├─ VK API (ваш токен)
                                                                              │   └─ maind --gst-launch playbin → ALSA
MidiPult player.py (состояние Алисы) ◄── раз в 1,5 с, пока играет: пауза, когда Алиса слушает/говорит
```

- **Доступ к ВК** — VK API от имени вашего аккаунта. Токен вы получаете сами через
  страницу входа ВК (клиент Kate Mobile — аудио-методы VK API отвечают только ему).
  Пароль служба не видит. Токен лежит в `/data/vk-music/token.json` (права 600).
- **«Моя волна»** — поток VK Микс (`audio.getStreamMixAudios`); если ВК не отдаёт его
  этому клиенту, служба берёт рекомендации (`audio.getRecommendations`). Очередь
  подгружается сама, пока волна играет.
- **Звук** — GStreamer прошивки через `maind --gst-launch`, как звуки MidiPult.
- **Алиса** — пока она слушает или говорит, музыка ВК на паузе. Если по вашей просьбе
  Алиса включила свою музыку, служба уступает и останавливается.

## Голосовые команды

Слово «ВК» можно заменить на «ВКонтакте». Без него команды уходят штатной Алисе.

| Скажите | Что будет |
|---|---|
| «Алиса, включи мою волну ВК», «…музыку ВК», «…ВК микс» | рекомендательный поток |
| «Алиса, включи мои треки ВК» | ваши треки вперемешку |
| «Алиса, пауза ВК» / «продолжи ВК» | пауза / продолжить |
| «Алиса, следующий трек ВК» / «предыдущий трек ВК» | переключение |
| «Алиса, лайк ВК» | добавить трек в «Мою музыку» |
| «Алиса, выключи ВК» | остановить |

Поиск по названию — на веб-странице (сценарии MidiPult не передают распознанный текст).

## Установка

Нужны root, Entware с `/opt/bin/python3` (3.9+) и установленный MidiPult.

```sh
# с компьютера
adb connect <ip-колонки>:5555
adb push vk-music /data/local/tmp/vk-music
adb shell sh /data/local/tmp/vk-music/deploy/install.sh
```

Установщик кладёт службу в `/data/vk-music`, ставит автозапуск
(`/opt/etc/init.d/S98vkmusic` и вызов из `/etc/init.d/S99zzvkmusic`) и добавляет
сценарии «ВК: …» в MidiPult. Затем откройте `http://<ip-колонки>:8061`, нажмите
«страница входа ВК», войдите и вставьте адрес открывшейся страницы.

Настройки — `/data/vk-music/config.json`:

| Ключ | По умолчанию | Зачем |
|---|---|---|
| `port` | 8061 | порт веб-страницы |
| `pin` | пусто | PIN для входа/выхода из ВК не с самой колонки |
| `voice_confirm` | true | Алиса говорит «Включаю мою волну ВК» |
| `player.cmd` | `maind --gst-launch playbin uri={url} audio-sink=alsasink` | своя команда плеера |
| `user_agent`, `client_id` | Kate Mobile | если ВК сменит клиента |

Управление: `/opt/etc/init.d/S98vkmusic {start|stop|restart|status}`, лог —
`/tmp/vk-music.log`. Отключить без удаления: `touch /data/vk-music/disabled`.
Удаление: `sh /data/local/tmp/vk-music/deploy/uninstall.sh` (с `--purge` — вместе со входом в ВК).

## HTTP API

| Адрес | Что делает |
|---|---|
| `GET /play/wave`, `/play/mine?shuffle=1`, `/play/search?q=…` | запустить (ответ сразу, 202) |
| `GET /pause` `/resume` `/toggle` `/next` `/prev` `/stop` `/like` | управление |
| `GET /api/status` | аккаунт, текущий трек, очередь |
| `GET /api/search?q=…`, `POST /api/play {"keys": [...]}` | поиск и запуск найденного |
| `POST /api/auth {"url"}`, `POST /api/logout` | вход / выход |

`?voice=1` у команд — режим голосового сценария: служба гасит ответ и музыку Алисы и
озвучивает ошибки.
